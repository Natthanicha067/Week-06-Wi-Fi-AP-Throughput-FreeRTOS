
# Lab 6.1
## ผลการทดลอง Wi-Fi SoftAP และ TCP Server บน ESP32

### 1. ผลการทดลอง

จากการทดลองพบว่า ESP32 สามารถทำงานในโหมด Wi-Fi SoftAP ได้สำเร็จ โดยสร้างเครือข่าย Wi-Fi ชื่อ `MY_ESP32_AP` และกำหนด IP Address เริ่มต้นเป็น `192.168.4.1`

ESP32 สามารถเปิด TCP Server ที่พอร์ต `8080` เพื่อรอรับการเชื่อมต่อจาก Client ได้ โดยทดสอบผ่านคำสั่ง `nc` บน Terminal และพบว่าสามารถเชื่อมต่อได้สำเร็จ พร้อมได้รับข้อความตอบกลับจาก ESP32 ดังนี้

```text
Connection to 192.168.4.1 port 8080 [tcp/http-alt] succeeded!
Hello ESP32
```

**ข้อมูลสำคัญจาก Serial Monitor**

| รายการ | ผลการทดลอง |
|---|---|
| ESP-IDF Version | v5.1.2 |
| Wi-Fi Mode | SoftAP |
| SSID | MY_ESP32_AP |
| Channel | 1 |
| Default IP Address | 192.168.4.1 |
| TCP Server Port | 8080 |
| TCP Server Status | Listening |
| การเชื่อมต่อ Client | สำเร็จ |
| ข้อความตอบกลับ | Hello ESP32 |

### 2. คำถามท้ายบท

**ข้อ 1. เหตุใด IP Address เริ่มต้นของ ESP32 SoftAP จึงเป็น 192.168.4.1 และ DHCP Server บน ESP32 เริ่มแจกจ่าย IP ที่หมายเลขใด?**

ตอบ: เนื่องจาก ESP32 กำหนด IP Address เริ่มต้นของ SoftAP เป็น `192.168.4.1` เพื่อใช้เป็น Gateway ของเครือข่าย และ DHCP Server จะเริ่มแจกจ่าย IP Address ให้ Client โดยเริ่มจาก `192.168.4.2`

**ข้อ 2. สมาชิกตัวแปร mac ในโครงสร้าง wifi_event_ap_staconnected_t สามารถนำไปประยุกต์ใช้ทำระบบความปลอดภัยขั้นสูง (เช่น MAC Filtering) ได้อย่างไร?**

ตอบ: สามารถนำ MAC Address ของอุปกรณ์ที่เชื่อมต่อมาเปรียบเทียบกับรายการ MAC Address ที่ได้รับอนุญาต หากตรงกับรายการจึงอนุญาตให้เชื่อมต่อหรือใช้งานระบบได้ แต่หากไม่ตรงจะปฏิเสธการเชื่อมต่อ ทั้งนี้ MAC Filtering เพียงอย่างเดียวไม่ใช่ระบบรักษาความปลอดภัยที่สมบูรณ์

**ข้อ 3. หากมี Client พยายามเชื่อมต่อเป็นเครื่องที่ 5 (เกินค่า max_connection = 4) จะเกิดเหตุการณ์ใดขึ้นในระดับสัญญาณวิทยุ?**

ตอบ: ESP32 จะไม่อนุญาตให้ Client เครื่องที่ 5 เชื่อมต่อเข้าสู่ SoftAP เนื่องจากมีจำนวนการเชื่อมต่อครบตามที่กำหนด โดยอุปกรณ์อาจส่งคำขอเชื่อมต่อผ่านคลื่นวิทยุได้ แต่ ESP32 จะปฏิเสธการเชื่อมต่อ ทำให้ไม่สามารถเข้าสู่เครือข่าย Wi-Fi ได้

### 3. สรุปผลการทดลอง

จากการทดลองสามารถกำหนดให้ ESP32 ทำงานในโหมด Wi-Fi SoftAP เพื่อสร้างเครือข่ายไร้สายของตนเองได้สำเร็จ พร้อมทั้งเปิด TCP Server เพื่อรับการเชื่อมต่อจาก Client ผ่านพอร์ต 8080 ผลการทดสอบพบว่า Client สามารถเชื่อมต่อกับ ESP32 และได้รับข้อความตอบกลับ `Hello ESP32` แสดงให้เห็นว่าการสื่อสารผ่าน TCP ระหว่าง ESP32 กับ Client ทำงานได้ตามที่กำหนด
